# 🎮 Joxia Games

Hub de jeux web gratuits : mini-jeux maison avec comptes, classements, amis et chat, plus une sélection de jeux open source de la communauté.

**▶ Jouer : https://joxiagame.github.io/Joxia-Games/**

## 🕹️ Jeux maison

Snake, Flappy, Tetris, Ball Blast, Brick Blast, 2048, Pac-Man, Codebreaker, Crypto Tycoon et Billard : un dépôt par jeu (`joxiagame/<Jeu>-Joxia`), scores enregistrés dans le classement du hub.

### Intégrer ces jeux

```bash
python scripts/import_leereilly_games.py                     # aperçu : ce qui serait forké
python scripts/import_leereilly_games.py --only hextris-joxia --apply
python scripts/import_leereilly_games.py --apply             # les 49 jeux ✅
```

Le script (GitHub CLI) forke chaque jeu dans `joxiagame`, ajoute `CREDITS.md`, un bandeau de crédits en tête du README et le traceur de temps de jeu, puis active GitHub Pages. Il ne modifie jamais un fichier de licence. Il affiche ensuite les cartes HTML à coller dans `index.html` et les entrées `PLAY_LABELS` du panneau admin.
